# Soft (Fin-Ray) gripper meshes

Visual meshes of Seeed's reBot soft gripper (finger + mount, left and right), in the
finger link frames of the reBot model. Copied from the `classic_real` branch
(`ros2_ws/src/rebot_trash_sorting/meshes/soft_gripper/visual/`). They were generated by
`ros2_ws/src/rebot_trash_sorting/scripts/build_soft_gripper_meshes.py` from Seeed's CAD
(`Soft_Gripper_Mount.step`, `Soft_Gripper_Finger.step`, reBot-DevArm, CERN-OHL-W).

`teleop/rebot_model.py` also uses the finger mesh for collisions. MuJoCo takes its convex
hull, a wedge with a flat gripping face. The ROS collision mesh is not used: it also covers
the mount area across the jaw, so its hull would fill the gap between the fingers.
